This is the repository of the Game "STRONGMEN". This game is the result of the "Gamification Seminar" (Summer Semester 2025) at the University of Vienna. 

This game is an adaptation of 'Strongmen – Mussolini to the Present' by Ruth Ben-Ghiat. Additional information can be found in the accompanying paper (Gamification Project Report)

Play the game here: https://notjona.github.io/Strongman/
